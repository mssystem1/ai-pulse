- **Radar create is blocked.** Unsigned public probes confirmed that the old Tapeout proxy returns HTTP 403 with a Cloudflare block page, while both official X Layer endpoints return chain ID 196. Both local readers now use the [documented official RPC pair](https://web3.okx.com/onchainos/dev-docs/xlayer/developer/rpc-endpoints/rpc-endpoints), retaining pinned-block agreement, registration, code, exact netlist and truth-table verification. A real read verified circuit 2 at block 76225194 with NAND outputs [1,1,1,0]. Agreement between these endpoints does not establish independent upstream operators. The market build and 61 market tests passed, as did 24 API monitoring/publication regressions. Radar creation still needs a production retest after deployment.
- **Creator Ask relevance was corrected locally.** The deployed creator-context answer returned HTTP 200 but mostly discussed BTC instead of the requested Studio comparison. The API now prioritizes the indicator workflow and omits unrelated setup context for Create indicator, Indicator Market and My indicators; explicitly requested setup analysis and pinned indicator evidence remain available. A real Grok 4.7 call using the new server prompt correctly compared both builders, previewing, chart application and optional publishing, without repeating unrelated synthetic BTC prices. Its answer is in ask-prompt-live-check.json. Context regression tests and the API build pass. The corrected production behavior remains pending deployment and retest. The local correction passed native-browser wheel, pan, axis and touch checks with zero measured quote-induced time-range drift.
